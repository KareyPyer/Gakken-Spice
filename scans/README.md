# Scans du manuel

Ce dossier ne contient **pas** les scans du manuel EX-SYSTEM lui-même
(droits d'auteur LANSAY/Gakken potentiellement toujours en vigueur selon les
pays). Il contient uniquement des **notes de lecture** au format Markdown
(`pXXX_notes.md`) décrivant, page par page :

- les composants utilisés et leurs valeurs annoncées,
- le comportement attendu (tension, fréquence, effet observé),
- toute ambiguïté de lecture du schéma qui a influencé les choix de
  modélisation dans `lib/`.

Si vous possédez le manuel et souhaitez partager les scans, faites-le via un
lien externe (archive personnelle, forum spécialisé) plutôt que de les
committer directement dans ce dépôt.
